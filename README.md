# Machine Learning for Wildfire Prediction

Proyecto final desarrollado en Talento Tech.

## Objetivo

Construir un pipeline de machine learning para analizar o predecir incendios forestales.

## Dataset

Dataset: [US Wildfire Dataset (2014-2025)](https://www.kaggle.com/datasets/firecastrl/us-wildfire-dataset)

## Estado del proyecto

El proyecto contiene actualmente el notebook original. Próximamente se agregarán comparaciones entre diferentes modelos.
